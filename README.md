# StockPy - Sistema de Controle de Estoque

Sistema de Controle de Estoque desenvolvido em Python puro, utilizando progrmação a objetos e persistênciaem JSON.

## Funcionalidades

- Cadastro e exclusão de produtos
- Consulta e listagem de produtos
- Registro e entradas de produtos
- Validação e estoque disponivel
- Cálculo do valor total de estoque
- Persistência dos dados em JSON

## Tecnologias 

- Python 
- JSON
- Dataclasses
- pathlib

## Como executar 

1 - Instale o Python 3.
2 - Clone este repositório.
3 - Entre na Pasta do Projeto.
4 - Execute:
    Python main.py

## Objetivos

Projeto educacional para praticar Python, organizarção de código e manipulação de arquivos
